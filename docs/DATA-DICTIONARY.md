# 纸上版税数据字典

## 来源文件

| 字段 | 定义 |
|---|---|
| 作者结算单 | 文本主键，保留前导零。跨业务键不汇并记录。 |
| 修订号 | 正整数。最高版优先；最高同版字段冲突或存在同版、更新版的未采信记录时隔离，旧版无法接替。 |
| 提交时间 | ISO 8601，必须带 UTC 偏移量。标准化后展示 UTC。 |
| 原始备注 | 可空，允许引号内换行。 |
| 期初净销、出库册数、实退册数、定价元、版税阶梯、留存百分比、释放准备金元 | 必填字段。多项字段用半角分号隔开，显式空集合用 `无`。 |

识别 `UTF-8`、UTF-8 BOM 与独立的 `GB18030` 文件。`业务编号`、`版本`、`更新时刻`、`备注` 为旧版表头别名。新旧名同时出现会被拒绝。`-`、`N/A`、`NULL`、`未知` 和空串均按必填值缺失处理。物理行号指 CSV 逻辑记录起始行。

## 计算字段

费档写成 `累计净销上限:费率百分比`，末档上限用 `*`。准备金留存只对正的净计提计算。

按同一份冻结合同先累计分档，再以实退冲掉最新销量对应的最高档份额。最终付款按分取半入。

复算证据逐档给出「档出库归属」（册）与「档净计提」（元）；结算单有实退时逐档补「档退货归属」（册），未占档记 0，退货只记总数也能看出逆冲落在哪一档。证据链末尾汇总「本期应付」（元）。

数值在服务端以十进制定点方式计算，对外按字符串传输。单文件上限 128 KiB，复合字段最多 240 个项目，个别字段还有业务上限。格式无法恢复的 CSV 整批拒绝，列数、缺字段、来源冲突和业务条件错误逐条隔离。

## 复算与外部清单

外部清单包含 `作者结算单` 和 `外部记录值(元)`，允许省略不在对账范围内的键。同一键重复会拒绝该清单。结果数值单位为 **元**。差值按本次复算减外部记录，缺一侧时差值计算以 0 占位并保留缺失原因。

同一对输入字节与规则版本生成同一批次，导出包含两个文件摘要、证据行、单边差异和复核修订记录。复核保存前检查当前版本，在有隔离、差异或退回时必须填写意见。外部账存在未核销差异时不能确认结清，只能退回并填写意见。批次结果写入后不可覆盖：指纹相同而内容冲突的写入被拒绝，旧结果与会签依据始终可恢复。
